Quick Start

Get up and running with Automergent in under two minutes

Terminal 
# 1. Install Automergent globally
$ npm install -g automergent

# 2. Authenticate with Google Cloud
$ automergent auth login
# Opens browser for Google OAuth — select your Vertex AI project

# 3. Initialize in your project
$ cd your-project/
$ automergent init
# Creates .automergent/config.json with sensible defaults

# 4. Start coding
$ automergent "add unit tests for the user service"

# Or enter interactive mode
$ automergent --interactive
Prerequisites

Node.js 18+ and a Google Cloud project with Vertex AI API enabled. For non-Google providers, set AI_PROVIDER environment variable.

Architecture

How Automergent processes tasks through its multi-phase pipeline

Pipeline 
// Automergent Processing Pipeline

Phase 1: Context Gathering
  → Semantic file discovery via AST analysis
  → Dependency graph construction
  → Relevant code extraction with token budgeting

Phase 2: Planning & Decomposition
  → Task decomposition into atomic units
  → Dependency graph for parallel execution
  → Sub-agent assignment by specialization

Phase 3: Parallel Execution
  → Specialist sub-agents execute in parallel
  → Each agent owns isolated file contexts
  → Conflict detection via file locking

Phase 4: Validation & Integration
  → Lint, type-check, and test execution
  → Automatic fix for detected issues
  → Git commit with conventional message

Configuration

Customize Automergent's behavior with a simple JSON config file

.automergent/config.json 
{
  "version": "1.0.0",
  "ai": {
    "provider": "gemini",
    "model": "gemini-2.5-pro",
    "fallback": "claude-sonnet-4-20250514",
    "temperature": 0.3,
    "maxTokens": 8192
  },
  "context": {
    "maxFiles": 50,
    "maxTokens": 120000,
    "includeTests": true,
    "excludePatterns": [
      "node_modules",
      "dist",
      "*.min.js"
    ]
  },
  "agents": {
    "maxParallel": 4,
    "timeout": 300000,
    "retryAttempts": 2
  },
  "theme": "dark",
  "git": {
    "autoCommit": true,
    "conventionalCommits": true,
    "branchPrefix": "automergent/"
  }
}

Command Reference

Complete list of available CLI commands and options

Command Description Options
automergent <task> Execute a coding task autonomously --interactive, --dry-run
automergent init Initialize config in current project --template <name>
automergent auth login Authenticate with your AI provider --provider <name>
automergent auth status Show current authentication status —
automergent config View or update configuration --set, --get, --reset
automergent context Show gathered context for a task --preview
automergent history View past task execution history --last <n>, --json
automergent doctor Run diagnostics and check setup --fix
automergent update Update to the latest version --check
