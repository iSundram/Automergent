Quick Start

Get up and running with Automergent in under two minutes

Terminal 
# 1. Install Automergent (one-line installer)
$ curl -fsSL https://automergent.github.io/install.sh | bash

# Or install via Go (requires Go 1.25+ with CGO enabled)
$ CGO_ENABLED=1 go install github.com/iSundram/Automergent/cmd/automergent@latest

# 2. Configure your AI provider (Google AI Studio, Vertex AI, OpenAI, Anthropic)
$ export GOOGLE_API_KEY="your-api-key"
# Or set in ~/.automergent/config.yaml

# 3. Run in your project
$ cd your-project/
$ automergent
# Creates ~/.automergent/config.yaml with sensible defaults on first run

# 4. Start coding
$ automergent "add unit tests for the user service"
Prerequisites

Go 1.25+ with CGO enabled (for building from source or Go install). An API key for your chosen AI provider: Google AI Studio (GOOGLE_API_KEY or GEMINI_API_KEY), Google Vertex AI, OpenAI (OPENAI_API_KEY), Anthropic (ANTHROPIC_API_KEY), or Ollama (local). Configure provider in ~/.automergent/config.yaml or via environment variables.

Architecture

How Automergent processes tasks through its 4-phase agent loop

Pipeline 
// Automergent 4-Phase Agent Loop

Phase 1 — INIT: Decompose & Route
  → Decompose user message into atomic parts
  → Route each part: direct answer / explore / plan / build
  → Serious, decisive persona; minimal tools (bash/read/edit/task)

Phase 2 — EXPLORE: Read-only Investigation
  → Semantic file discovery via AST analysis
  → Violation confirmation & issue-suspect investigation
  → Report file:line findings; no edits

Phase 3 — PLAN: Architect & Design
  → Consume INIT constraints & exploration findings
  → Produce structured plan (objective/changes/risks/verification)
  → Ask when ambiguous; respect user-suggested approaches

Phase 4 — BUILD: Implement & Verify
  → Todo discipline; test-after-change
  → Sub-agent delegation for parallel work
  → Transition back to EXPLORE when blocked

Configuration

Customize Automergent's behavior with a simple YAML config file

~/.automergent/config.yaml 
# Core settings
provider: google-aistudio   # google-aistudio | google-vertex | custom
model: gemini-3.6-flash       # default model
mode: accept-edits            # manual | accept-edits | auto | plan
theme: modern                 # modern | catppuccin | tokyonight | dracula | nord | gruvbox | onedark | solarized-dark | solarized-light | high-contrast | monokai
keybindings: default          # default | vim | emacs

# Context window management
maxContextTokens: 1048576     # 1M token ceiling
maxToolOutputChars: 32768     # 32k chars per tool output
autoCompressAt: 0.55          # auto-compact trigger fraction

# Provider-specific settings
providers:
  gemini:
    apiKey: "${GOOGLE_API_KEY}"
  openai:
    apiKey: "${OPENAI_API_KEY}"
  anthropic:
    apiKey: "${ANTHROPIC_API_KEY}"

# Security sandbox
sandbox: auto                 # auto | bubblewrap | seatbelt | noop
blockedWritePaths:
  - "/etc/**"
  - "/usr/**"
allowedWritePaths:
  - "."

# Git settings
git:
  coAuthor: ask               # always | never | ask
