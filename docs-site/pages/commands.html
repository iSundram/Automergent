Session Management

/new — Start a New Session
SyntaxDescriptionExampleRelated
/new [name] Create a fresh session. Optionally provide a name to identify it later. /new auth-refactor /sessions /resume
/sessions — List All Sessions
SyntaxDescriptionExampleRelated
/sessions Display all saved sessions with names, dates, and message counts. /sessions /resume
/resume — Resume a Session
SyntaxDescriptionExampleRelated
/resume [id|name] Load a previous session by ID or name. Without arguments, shows a picker. /resume auth-refactor /sessions /branch
/rename — Rename Current Session
SyntaxDescriptionExampleRelated
/rename <new-name> Give the current session a memorable name. /rename oauth2-impl /sessions
/branch — Branch a Session
SyntaxDescriptionExampleRelated
/branch [name] Create a fork of the current session to explore alternative approaches without losing history. /branch alt-approach /resume /sessions
/quit — Exit Automergent
SyntaxDescriptionExampleRelated
/quit Save the current session and exit the application. /quit /sessions

AI Model & Provider

/model — Switch AI Model
SyntaxDescriptionExampleRelated
/model [model-name]
/model list
/model info <name>
/model refresh		 Change the active AI model, or inspect the catalog: list shows every supported model with context limit and pricing, info shows full details for one model, and refresh re-fetches the models.dev catalog. Model listings come from the models.dev community catalog — filtered to tool-call capable models with at least 1M tokens of context — and work fully offline via a disk cache and an embedded snapshot. /model gemini-3.6-flash /model info claude-sonnet-4-5 /provider /effort
/provider — Manage Providers
SyntaxDescriptionExampleRelated
/provider [name] List or switch AI providers (openai, anthropic, google, azure, etc.). /provider anthropic /model /api-key
/provider test — Test Provider Connection
SyntaxDescriptionExampleRelated
/provider test [provider] Verify API connectivity and credentials for the specified or active provider. /provider test openai /provider /doctor
/provider fallback — Configure Fallback Chain
SyntaxDescriptionExampleRelated
/provider fallback [chain] Set the fallback order when a provider is unavailable. Chain is comma-separated. /provider fallback openai,anthropic,google /provider
/provider api-key — Set Provider API Key
SyntaxDescriptionExampleRelated
/provider api-key <provider> <key> Store an API key for a specific provider. Key is encrypted at rest. /provider api-key openai sk-... /api-key /provider
/provider base-url — Set Provider Base URL
SyntaxDescriptionExampleRelated
/provider base-url <provider> <url> Override the API endpoint for a provider (useful for proxies or local models). /provider base-url openai http://localhost:8080/v1 /base-url /provider
/api-key — Quick API Key
SyntaxDescriptionExampleRelated
/api-key [key] Shorthand to set the API key for the current provider. Reads from stdin if no argument. /api-key sk-ant-... /provider api-key /provider
/base-url — Quick Base URL
SyntaxDescriptionExampleRelated
/base-url [url] Shorthand to set the API base URL for the current provider. /base-url http://127.0.0.1:11434 /provider base-url
/effort — Set Reasoning Effort
SyntaxDescriptionExampleRelated
/effort <low|medium|high> Adjust the reasoning depth. Higher effort = more thorough but slower and more expensive. /effort high /effort low /model /cost

Approval Modes

/mode — Switch Approval Mode
SyntaxDescriptionExampleRelated
/mode [mode] Toggle between approval modes: full-auto, semi-auto, plan, ask. Without arguments, shows current mode. /mode full-auto /mode semi-auto /permissions
/permissions — Manage Permissions
SyntaxDescriptionExampleRelated
/permissions [scope] View or set per-command permission overrides. Use global, project, or session scope. /permissions /permissions project /permissions add /mode
/permissions add — Allow a Command
SyntaxDescriptionExampleRelated
/permissions add <pattern> Auto-approve matching commands without prompting. Supports glob patterns. /permissions add "git commit*" /permissions remove
/permissions remove — Revoke a Permission
SyntaxDescriptionExampleRelated
/permissions remove <pattern> Remove an auto-approval rule. The command will require manual approval again. /permissions remove "git commit*" /permissions add
/permissions clear — Reset Permissions
SyntaxDescriptionExampleRelated
/permissions clear [scope] Remove all permission overrides for the given scope (or all scopes). /permissions clear session /permissions

Context & Memory

/context — View Context Window
SyntaxDescriptionExampleRelated
/context Display current context window usage: tokens consumed, remaining, and breakdown by source. /context /compact /context detail
/context detail — Detailed Context Breakdown
SyntaxDescriptionExampleRelated
/context detail Show a detailed breakdown of context usage per file, memory, and system prompt. /context detail /context /compact
/compact — Compact Context
SyntaxDescriptionExampleRelated
/compact [instruction] Summarize and compress the conversation to free up context space. Optional instruction guides what to preserve. /compact keep the auth discussion /context /tldr
/context-files — List Context Files
SyntaxDescriptionExampleRelated
/context-files Show all files currently loaded into context and their token counts. /context-files /context /add-dir
/memory — View Memory Entries
SyntaxDescriptionExampleRelated
/memory Display all persistent memory entries that persist across sessions. /memory /memory add /memory remove
/memory add — Add Memory Entry
SyntaxDescriptionExampleRelated
/memory add <text> Store a persistent note that will be included in future sessions automatically. /memory add "Use PostgreSQL, never MySQL" /memory /memory remove
/memory remove — Remove Memory Entry
SyntaxDescriptionExampleRelated
/memory remove <text|id> Delete a memory entry by partial text match or index number. /memory remove 2 /memory add
/memory clear — Clear All Memory
SyntaxDescriptionExampleRelated
/memory clear Delete all persistent memory entries. Requires confirmation. /memory clear /memory
/dream — Dream Mode
SyntaxDescriptionExampleRelated
/dream [prompt] Enter a creative exploration mode where the AI can brainstorm, prototype, and iterate freely without approval gates. /dream redesign the dashboard with a sidebar layout /mode /plan
/add-dir — Add Directory to Context
SyntaxDescriptionExampleRelated
/add-dir <path> Include additional directories in the AI's context for cross-module awareness. /add-dir ../shared-lib /directory /context-files
/directory — View Current Directories
SyntaxDescriptionExampleRelated
/directory List all directories currently included in context. /directory /add-dir /context-files

Planning & Artifacts

/plan — Generate Execution Plan
SyntaxDescriptionExampleRelated
/plan [goal] Generate a step-by-step execution plan before making changes. Without a goal, plans based on the last message. /plan implement OAuth2 login flow /plan copy /goal
/plan copy — Copy Plan to Clipboard
SyntaxDescriptionExampleRelated
/plan copy Copy the current execution plan to clipboard for sharing or documentation. /plan copy /plan /export
/artifact — Manage Artifacts
SyntaxDescriptionExampleRelated
/artifact [list|show|export] View or export generated artifacts (files, docs, configs) created during the session. /artifact list /artifact export /plan /export
/goal — Set Session Goal
SyntaxDescriptionExampleRelated
/goal <description> Define a high-level goal that guides the AI's decisions and helps track progress. /goal migrate from REST to GraphQL /goal pause|resume|continue|clear /plan
/goal pause|resume|continue|clear — Goal Controls
SyntaxDescriptionExampleRelated
/goal pause Pause goal tracking without clearing the goal. /goal pause /goal
/goal resume Resume a paused goal. /goal resume /goal
/goal continue Same as resume — continue tracking the active goal. /goal continue /goal
/goal clear Remove the current goal entirely. /goal clear /goal

Code Review

/review — Review Code Changes
SyntaxDescriptionExampleRelated
/review [scope] Review uncommitted changes or a specific commit. Analyzes code quality, bugs, and suggestions. /review /review HEAD~3 /review-mode /diff
/review-mode — Set Review Depth
SyntaxDescriptionExampleRelated
/review-mode <quick|standard|deep> Configure how thorough code reviews are. Deep includes security, performance, and style analysis. /review-mode deep /review /security-review
/security-review — Security Audit
SyntaxDescriptionExampleRelated
/security-review [scope] Focused security audit looking for vulnerabilities, injection risks, auth flaws, and data leaks. /security-review src/auth/ /review /review-mode
/diff — Show Changes
SyntaxDescriptionExampleRelated
/diff [ref] Display unified diff of uncommitted changes or vs a specific git ref. /diff /diff main /review /commit

Build & Test

/build — Run Build
SyntaxDescriptionExampleRelated
/build [target] Run the project's build command. Detects package manager and framework automatically. /build /build prod /test /run
/test — Run Tests
SyntaxDescriptionExampleRelated
/test [filter] Run test suite. Optional filter matches test names. Auto-detects framework (jest, vitest, pytest, etc.). /test /test auth /build /run
/run — Execute Command
SyntaxDescriptionExampleRelated
/run <command> Execute an arbitrary shell command with output capture. Use ! prefix as shorthand. /run npm start !ls -la /build /test
/lsp — Check LSP Diagnostics
SyntaxDescriptionExampleRelated
/lsp [file] Show LSP errors and warnings for a file or the current file. Highlights type errors, lint issues, etc. /lsp /lsp src/app.ts /lsp all
/lsp all — All LSP Diagnostics
SyntaxDescriptionExampleRelated
/lsp all Aggregate LSP diagnostics across all open files and the workspace. /lsp all /lsp /doctor

Git & GitHub

/commit — Create Git Commit
SyntaxDescriptionExampleRelated
/commit [message] Stage all changes and commit with a generated or provided message. Follows conventional commits. /commit /commit "feat: add OAuth2 flow" /diff /pr-comments
/issue — Create GitHub Issue
SyntaxDescriptionExampleRelated
/issue [title] Create a GitHub issue from the current context. Auto-fills title, body, and labels. /issue login timeout in production /pr-comments /commit
/pr-comments — Review PR Comments
SyntaxDescriptionExampleRelated
/pr-comments [pr#] Fetch and display review comments from a pull request. Can address feedback interactively. /pr-comments 42 /review /commit
/search — Search Codebase
SyntaxDescriptionExampleRelated
/search <query> Search for files, functions, or patterns across the codebase with context-aware results. /search handleAuth /context-files /add-dir

Inspection

/doctor — Health Check
SyntaxDescriptionExampleRelated
/doctor Run diagnostics: verify API keys, provider connectivity, LSP servers, git status, config validity, and the models.dev catalog state (cache freshness, embedded snapshot fallback) for the active provider. /doctor /provider test /config
/env — Show Environment
SyntaxDescriptionExampleRelated
/env Display environment info: OS, shell, node version, git version, PATH entries relevant to tools. /env /version /doctor
/version — Show Version
SyntaxDescriptionExampleRelated
/version Display Automergent version, build info, and changelog link. /version /doctor /env
/config — View/Edit Configuration
SyntaxDescriptionExampleRelated
/config [key] [value] View all config or get/set a specific key. Config is stored in .automergent/config.json. /config /config theme dark /theme /doctor
/error — View Error Log
SyntaxDescriptionExampleRelated
/error Display recent errors, warnings, and failed commands from the current session. /error /error clear /doctor
/error clear — Clear Error Log
SyntaxDescriptionExampleRelated
/error clear Clear the error log for the current session. /error clear /error
/stats — Session Statistics
SyntaxDescriptionExampleRelated
/stats Display session metrics: messages, tokens, tool calls, duration, and files modified. /stats /cost /recap
/cost — Show Cost Estimate
SyntaxDescriptionExampleRelated
/cost Estimate API cost based on tokens used and current model pricing. /cost /stats /effort
/recap — Session Recap
SyntaxDescriptionExampleRelated
/recap Generate a summary of everything accomplished in the current session: changes, decisions, and next steps. /recap /summary /tldr
/summary — Generate Summary
SyntaxDescriptionExampleRelated
/summary [prompt] AI-generated summary of conversation progress. Custom prompt guides the summary focus. /summary focus on architecture decisions /recap /tldr
/tldr — Quick TL;DR
SyntaxDescriptionExampleRelated
/tldr One-paragraph ultra-concise summary of the session. Great for sharing with teammates. /tldr /recap /summary
/export — Export Session
SyntaxDescriptionExampleRelated
/export [format] Export the full session as markdown, JSON, or HTML. Defaults to markdown. /export /export json /recap /plan copy

UI & Display

/theme — Change Theme
SyntaxDescriptionExampleRelated
/theme [name] Switch between themes: dark, light, mono, high-contrast. Without arguments, cycles themes. /theme light /config
/keybindings — View Keybindings
SyntaxDescriptionExampleRelated
/keybindings [vim|emacs|default] Show or switch keybinding preset. Supports default, vim, and emacs modes. /keybindings vim Keyboard Shortcuts
/help — Show Help
SyntaxDescriptionExampleRelated
/help [command] Display help for a specific command or list all commands. Press ? as a shortcut. /help /help model /commands
/commands — List All Commands
SyntaxDescriptionExampleRelated
/commands [filter] Browse all available commands. Optional filter matches command names. /commands git /help
/tree — Show File Tree
SyntaxDescriptionExampleRelated
/tree [path] [--depth N] Display directory tree. Supports depth limiting and filtering by extension. /tree src/ --depth 3 /directory /add-dir
/cancel — Cancel Current Operation
SyntaxDescriptionExampleRelated
/cancel Interrupt the current AI generation or tool execution. Press Esc as a shortcut. /cancel /quit

Skills & Extensions

/skills — Manage Skills
SyntaxDescriptionExampleRelated
/skills [list|enable|disable|info] Browse, enable, or disable built-in and custom skills that extend AI capabilities. /skills list /skills enable code-review /mcp /workflow
/mcp — MCP Server Management
SyntaxDescriptionExampleRelated
/mcp [list|status] View connected MCP (Model Context Protocol) servers and their status. /mcp list /mcp status /mcp tools /mcp add
/mcp tools — List MCP Tools
SyntaxDescriptionExampleRelated
/mcp tools [server] List all tools exposed by connected MCP servers. Filter by server name. /mcp tools /mcp tools filesystem /mcp /mcp enable|disable
/mcp enable|disable — Toggle MCP Servers
SyntaxDescriptionExampleRelated
/mcp enable <server> Connect to and activate an MCP server. /mcp enable filesystem /mcp
/mcp disable <server> Disconnect from an MCP server. /mcp disable filesystem /mcp
/mcp add — Add MCP Server
SyntaxDescriptionExampleRelated
/mcp add <name> <command> Register a new MCP server by providing its name and launch command. Stored in config. /mcp add github npx @modelcontextprotocol/server-github /mcp /mcp tools
/workflow — Execute Workflow
SyntaxDescriptionExampleRelated
/workflow [name] Run a predefined multi-step workflow (e.g., deploy, release, lint-fix). Without arguments, lists available workflows. /workflow deploy /plan /skills
/agents — Manage Sub-Agents
SyntaxDescriptionExampleRelated
/agents [list|spawn|kill] Manage parallel sub-agents that work on independent tasks simultaneously. /agents list /agents spawn "write tests for auth" /workflow /skills
/feedback — Send Feedback
SyntaxDescriptionExampleRelated
/feedback [message] Submit feedback, bug reports, or feature requests. Opens browser to the issue tracker. /feedback the /plan command is great! /version
