# /tree

Toggles the workspace file tree sidebar: a live directory view next to the
conversation, handy for orientation in unfamiliar projects.

## Notes
- Takes roughly a fifth of the width when open.
- Hidden directories are skipped; large trees collapse sensibly.
- Purely a view toggle — the agent's file access is unaffected.

## Related
- `/files` — the files the agent actually touched this session.
- `/directory` — the working directory the agent operates in.
