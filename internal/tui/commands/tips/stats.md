# /stats

Opens the statistics dashboard: input/output tokens, cost, tool-call
counts and model usage for the current session.

## Usage
- `/stats` — the dashboard view.

## Notes
- Token totals update live as the session progresses.
- Cost uses the provider's published pricing when available.

## Related
- `/cost` — the one-line version.
- `/context` — window usage rather than totals.
