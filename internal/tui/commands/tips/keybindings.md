# /keybindings

Switches the keybinding scheme: default, vim or emacs navigation grammar
across the prompt, browsers and overlays.

## Usage
- `/keybindings` — list schemes and show the current one.
- `/keybindings <scheme>` — switch.

## Notes
- The `?` help overlay reflects the active scheme's keys.
- Persisted with the project config.

## Related
- `/config` — the stored settings view.
