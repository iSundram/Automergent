# /theme

Switches the color theme (modern, catppuccin, dracula, ...). The change
applies instantly across header, palette, browsers and diff views, and
persists in the project config.

## Usage
- `/theme` — list themes and show the current one.
- `/theme <name>` — switch.

## Notes
- Terminal color depth is respected; degraded palettes stay legible.
- The change is persisted to the project config on success.

## Related
- `/config` — where the setting is stored.
