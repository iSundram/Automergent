# /help

Opens the help overlay: keybindings for the active scheme, the full command
reference grouped by category, and mode explanations.

## Usage
- `/help` or `?` — open.
- `esc` or `?` — close.

## Notes
- The reference is generated from the live command registry, so custom
  commands appear automatically.
- Each command's comprehensive tips (this material) back its entry.

## Related
- `/commands` — the raw registry listing.
